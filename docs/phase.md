CHI TIẾT CÁC GIAI ĐOẠN LẬP TRÌNH (PHASE DETAILS)1. Phase 1: Setup Khung Dự án & Server BaseMục tiêu: Tạo môi trường chạy Node.js với ES Modules, cấu hình Git chuẩn và dựng khung thư mục 4 tầng SRP.Entry Criteria (Đầu vào):Node.js (phiên bản LTS) đã được cài đặt trên máy.Đã mở Terminal tại thư mục dự án hvn-khkt-task-002.Nhiệm vụ lập trình (Coding Tasks):Tạo file .gitignore chứa: node_modules/, .env, logs/.Khởi tạo package.json với "type": "module", cài đặt dependency express và cors.Tạo cấu trúc thư mục:src/
├── database/
├── services/
├── controllers/
└── routes/
public/
Viết src/server.js: Đăng ký express.json(), cors(), cấu hình express.static('public') và endpoint test GET /ping.Exit Criteria (Tiêu chí hoàn thành Phase 1):Lệnh npm run dev hoặc node src/server.js khởi chạy thành công cổng 3000.Gọi GET http://localhost:3000/ping bằng Postman/Trình duyệt nhận phản hồi { success: true, message: "pong" }.2. Phase 2: Triển khai Database & Service Layer (Data & Business Logic)Mục tiêu: Xây dựng kho lưu trữ dữ liệu trong RAM và toàn bộ logic nghiệp vụ (validate, lọc, sắp xếp, tính toán).Entry Criteria (Đầu vào): Phase 1 hoàn thành thành công.Nhiệm vụ lập trình (Coding Tasks):File src/database/profile.database.js:Khai báo mảng profiles mẫu và biến đếm nextId.Triển khai các hàm async: getAll(), getById(id), create(data), update(id, data), patch(id, data), delete(id), findByEmailOrPhone(email, phone, excludeId).File src/services/profile.service.js:Hàm getAllProfiles(queryParams): Áp dụng JavaScript array methods để tự động tính age, lọc search (tên), lọc gender, sắp xếp sortBirthYear (asc/desc).Hàm createProfile(data): Validate bắt buộc đủ trường; validate năm sinh hợp lệ (1900 - hiện tại); validate trùng email hoặc phone.Áp dụng Result Object Pattern: Phản hồi dạng { isSuccess: true, data } hoặc { isSuccess: false, statusCode, message }.Exit Criteria (Tiêu chí hoàn thành Phase 2):Đã export đầy đủ profileDb và profileService.Không sử dụng bất kỳ đối tượng Express nào (req, res) trong hai file này.3. Phase 3: Triển khai Controller & Route Layer (HTTP Routing & Response Handling)Mục tiêu: Bóc tách dữ liệu từ HTTP Request, gọi Service xử lý và trả về chuẩn Response Entity kèm HTTP Status Code.Entry Criteria (Đầu vào): Phase 2 hoàn thành thành công.Nhiệm vụ lập trình (Coding Tasks):File src/controllers/profile.controller.js:Triển khai 6 handler: getAll, getById, create, update, patch, delete.Kiểm tra quy chuẩn Strict PUT: Yêu cầu req.body phải chứa đầy đủ 5 trường (fullName, birthYear, gender, email, phone).Trả về đúng HTTP Status Code (200, 201, 204, 400, 404, 500).Chuẩn hóa Response Entity: { success: true/false, message, data } (riêng DELETE trả 204 No Content không body).File src/routes/profile.route.js:Khai báo Express Router và gắn 6 router endpoints tương ứng với Controller handler.Tích hợp vào Server: Import Router vào server.js qua app.use('/profiles', profileRoutes).Exit Criteria (Tiêu chí hoàn thành Phase 3):Test thành công cả 6 endpoints bằng Postman/Bruno/Thunder Client.Kiểm tra đúng status code: POST tạo thành công trả 201, gửi thiếu dữ liệu trả 400, DELETE trả 204.4. Phase 4: Phát triển Frontend Single-Page & Tích hợp APIMục tiêu: Xây dựng giao diện web động sử dụng JavaScript thuần (fetch()) kết nối với Backend API mà không làm reload trang.Entry Criteria (Đầu vào): Toàn bộ API ở Phase 3 hoạt động ổn định trên Postman.Nhiệm vụ lập trình (Coding Tasks):File public/index.html:Dựng Form nhập dữ liệu (Họ tên, Năm sinh, Giới tính, Email, SĐT).Dựng bộ lọc tìm kiếm (Ô nhập tên, Ô chọn giới tính).Dựng bảng hiển thị danh sách profile.File public/script.js:Lắng nghe sự kiện submit Form -> Gọi POST /profiles -> Reload lại danh sách.Gọi fetchProfiles() khi trang vừa load -> GET /profiles kèm query params nếu có.Xử lý sự kiện click nút "Xóa" -> Gọi DELETE /profiles/:id -> Nhận Status 204 -> Cập nhật lại UI.Exit Criteria (Tiêu chí hoàn thành Phase 4):Mở http://localhost:3000 trên trình duyệt hiển thị giao diện.Thao tác Thêm, Lọc, Xóa hoạt động mượt mà, không xảy ra hiện tượng tải lại trang web.5. Phase 5: Global Error Handling Middleware & Tối ưu hóa (Refactor & QA)Mục tiêu: Tập trung hóa quy trình xử lý lỗi bằng Middleware của Express và rà soát lại toàn bộ tiêu chí chấm điểm.Entry Criteria (Đầu vào): Frontend và Backend đã kết nối thành công.Nhiệm vụ lập trình (Coding Tasks):File src/middlewares/error.middleware.js:Viết Middleware bắt lỗi 4 tham số (err, req, res, next).Cấu hình phản hồi lỗi đồng nhất: { success: false, message: err.message }.Refactor Controller: Chuyển các lỗi ngoại lệ không dự đoán trước về next(err) để Middleware xử lý.Rà soát lại Rubric chấm điểm (Quality Gate Checklist):[x] CRUD đầy đủ (30đ)[x] Hiểu đúng HTTP Methods (20đ)[x] Đúng HTTP Status Code (15đ)[x] Response Entity thống nhất (10đ)[x] Cấu hình CORS đúng (5đ)[x] Tách 4 tầng SRP (15đ)[x] Frontend gọi fetch() không reload (5đ)[x] File .gitignore và Git chuẩn (5đ)Exit Criteria (Tiêu chí hoàn thành Phase 5):Đạt tối đa điểm theo Rubric đánh giá (100/100).Mã nguồn sạch đẹp, có comment giải thích rõ ràng các tầng kiến trúc.
